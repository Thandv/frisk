usage: frisk [-h] [--mcp-config FILE] [--text STR] [--json] [--sarif] [--sarif-out FILE]
             [--max-file-bytes N] [--fail-on {block,warn,never}] [-q] [-V]
             [targets ...]

Static, zero-execution security scanner for AI-agent content (MCP servers, Claude Code
skills/plugins/subagents, Cursor rules). Subcommands: lock, verify, proxy.

positional arguments:
  targets               local paths and/or git URLs to scan; an MCP config file is audited as with
                        --mcp-config

options:
  -h, --help            show this help message and exit
  --mcp-config FILE     audit every server in an MCP config file (repeatable)
  --text STR            scan a raw string instead of a path
  --json                emit findings as JSON
  --sarif               emit SARIF 2.1.0 (GitHub code scanning)
  --sarif-out FILE      also write SARIF 2.1.0 to FILE; the report is printed as usual and the
                        exit code is unchanged
  --max-file-bytes N    skip files larger than N bytes (a block finding), and match only the first
                        and last N/2 characters of a longer --text (a warning) (default: 2097152)
  --fail-on {block,warn,never}
                        exit non-zero when the worst finding reaches this level (default: block)
  -q, --quiet           print only the verdict line
  -V, --version         show program's version number and exit
