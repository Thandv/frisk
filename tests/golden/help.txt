usage: frisk [-h] [--mcp-config FILE] [--text STR] [--stdin] [--json] [--sarif] [--sarif-out FILE]
             [--max-file-bytes N] [--fail-on {block,warn,never}] [-q] [-V]
             [targets ...]

Static, zero-execution security scanner for AI-agent content (MCP servers,
Claude Code skills/plugins/subagents, Cursor rules).

positional arguments:
  targets               local paths and/or git URLs to scan; an MCP config file is audited as with
                        --mcp-config

options:
  -h, --help            show this help message and exit
  --mcp-config FILE     audit every server in an MCP config file (repeatable)
  --text STR            scan a raw string instead of a path
  --stdin               scan text read from standard input: at most --max-file-bytes bytes are
                        read, and longer input warns (coverage.truncated)
  --json                emit findings as JSON
  --sarif               emit SARIF 2.1.0 (GitHub code scanning)
  --sarif-out FILE      also write SARIF 2.1.0 to FILE; the report is printed as usual and the
                        exit code is unchanged
  --max-file-bytes N    skip files larger than N bytes (a block finding), and match only the first
                        and last N/2 characters of a longer --text (a warning) (default: 2097152)
  --fail-on {block,warn,never}
                        exit non-zero when the worst finding reaches this level (default: block)
  -q, --quiet           print only the verdict line
  -V, --version         show program's version number and exit

subcommands:
  frisk [options] TARGET ...    scan (this help)
  frisk lock                    pin a content fingerprint of approved content (frisk lock --help)
  frisk verify                  re-check pinned content for drift (frisk verify --help)
  frisk proxy [options] -- CMD  check an MCP server's tools at runtime (frisk proxy: usage)

exit status of a scan:
  0  no finding reached the --fail-on level (always 0 with --fail-on never)
  1  the worst finding reached the --fail-on level (default: block)
  2  a usage error, no target, or a target, MCP config, --stdin or --sarif-out FILE that
     cannot be read or written (a file inside a target that cannot be read is a warning)
frisk lock exits 0, or 2 on an error. frisk verify exits 0, 1 on drift or an entry it could
not verify, 2 on a lockfile it cannot read. frisk proxy exits with the server's status, or 2
on a usage error or a server it cannot start.
